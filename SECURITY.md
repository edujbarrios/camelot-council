# Security Policy

Camelot Council is a prompt/protocol repository for OpenAI Codex. It does not ship a network service, dependency package, or hosted runtime by default.

## Supported Versions

Security updates apply to the latest state of the default branch.

## Reporting a Vulnerability

Please do not open a public issue for sensitive security reports.

Use GitHub private vulnerability reporting when available, or contact the repository owner through GitHub with:

- A short summary.
- Steps to reproduce or inspect the issue.
- Affected files or commands.
- Potential impact.
- Suggested fix, if known.

## Relevant Security Issues

Examples that belong here:

- Installer behavior that could overwrite unexpected paths.
- Prompt or skill instructions that encourage unsafe file loading.
- Agent/config behavior that leaks unnecessary context.
- Documentation that creates unsafe operational guidance.

Examples that usually do not belong here:

- A disagreement about an agent's reasoning style.
- A request for a new triad or profile.
- General model-quality concerns without a specific exploit path.

## Maintainer Response

The maintainer will aim to acknowledge valid reports, assess impact, and publish a fix or mitigation note when practical.
