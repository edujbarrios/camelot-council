# Camelot Council

Camelot Council is a Codex-first structured deliberation skill. The primary operating file is `SKILL.codex.md`.

Use this skill when a user invokes `/roundtable` or asks Codex to run an Arthurian Round Table review over a decision, design, plan, code change, risk, or strategy.

## Codex-First Path

1. Read `SKILL.codex.md`.
2. Select only the agents required by the requested mode, triad, profile, or explicit member list.
3. Load the selected `agents/*.md` files.
4. Run the requested deliberation mode.
5. Return a compact verdict with unresolved questions and next actions.

This project does not require Claude Code and does not provide a Claude-first workflow.
