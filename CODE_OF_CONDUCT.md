# Code of Conduct

Camelot Council is an open-source project for structured AI-assisted deliberation. Contributors and users are expected to keep discussion respectful, practical, and welcoming.

## Expected Behavior

- Use considerate language.
- Assume good intent while staying accountable for impact.
- Keep critique focused on ideas, code, documentation, and project direction.
- Welcome beginners and first-time contributors.
- Respect boundaries, privacy, and differing levels of availability.

## Unacceptable Behavior

- Harassment, insults, threats, or sustained personal attacks.
- Discriminatory language or conduct.
- Publishing private information without consent.
- Bad-faith disruption, spam, or repeated off-topic arguments.
- Sexualized attention or other conduct inappropriate for a professional project space.

## Enforcement

Project maintainers may remove comments, close issues, decline contributions, or restrict participation when behavior harms the project community.

To report a concern, contact the maintainer through the repository owner profile or by opening a private security advisory if the issue involves sensitive project safety.

## Scope

This code applies in project spaces including GitHub issues, pull requests, discussions, and related community channels.
