# Support

Camelot Council is maintained as an open-source project.

## Where To Ask

- Use GitHub issues for reproducible bugs, missing files, documentation problems, and clear feature requests.
- Use pull requests for focused improvements.
- Use discussions, if enabled, for broader ideas and usage questions.

## Before Opening An Issue

Please check:

- The latest `README.md`.
- `SKILL.codex.md` for command behavior.
- Existing issues and pull requests.
- `scripts/validate-structure.sh` for expected files.

## Scope

The project can help with:

- Codex skill workflow.
- Markdown agent format.
- Triads and profiles.
- Installation script behavior.
- Documentation clarity.

The project cannot provide official support for OpenAI Codex itself.
